# Project Azaadi 🚀

**A Platform-Independent C Compiler and Virtual Machine**

Project Azaadi is a complete implementation of a C-to-bytecode compiler and stack-based virtual machine, making C programs truly platform-independent.

---

## 📋 Project Structure

```
Project Azaadi/
├── token.h              # Token definitions
├── lexer.c              # Lexical analyzer
├── ast.h                # Abstract Syntax Tree definitions
├── ast.c                # AST implementation
├── parser.c             # Parser (builds AST)
├── bytecode.h           # Bytecode definitions
├── bytecode.c           # Bytecode operations
├── codegen.c            # Code generator (AST → Bytecode)
├── compiler_main.c      # Compiler entry point
├── vm.c                 # Virtual Machine
├── vm_main.c            # VM entry point
├── Makefile             # Build system
└── test.c               # Sample test program
```

## 🔧 Building the Project

### Prerequisites
- GCC or any C99-compatible compiler
- Make build tool

### Compilation

```bash
# Build everything
make

# This creates two executables:
# - azaadicc (the compiler)
# - azaadi   (the virtual machine)
```

---

## 🎯 Usage

### Step 1: Compile a C Program

```bash
./azaadicc input.c output.azb
```

Example:
```bash
./azaadicc test.c test.azb
```

This reads `test.c`, compiles it, and produces `test.azb` (Azaadi bytecode).

### Step 2: Run the Bytecode

```bash
./azaadi bytecode.azb
```

Example:
```bash
./azaadi test.azb
```

This loads and executes the bytecode file.

## 🏗️ Architecture

### Compilation Pipeline

```
C Source Code
    ↓
[Lexer] → Tokens
    ↓
[Parser] → Abstract Syntax Tree (AST)
    ↓
[Code Generator] → Azaadi Bytecode
    ↓
.azb file
```

### Execution Pipeline

```
.azb file
    ↓
[Bytecode Loader]
    ↓
[Stack-based VM]
    ↓
Program Output
```

## 🔍 Bytecode Instruction Set

| Instruction | Description |
|------------|-------------|
| `PUSH`     | Push constant onto stack |
| `POP`      | Pop value from stack |
| `ADD`      | Add top two values |
| `SUB`      | Subtract |
| `MUL`      | Multiply |
| `DIV`      | Divide |
| `MOD`      | Modulo |
| `NEG`      | Negate top value |
| `EQ`       | Equal comparison |
| `NE`       | Not equal |
| `LT`       | Less than |
| `LE`       | Less or equal |
| `GT`       | Greater than |
| `GE`       | Greater or equal |
| `NOT`      | Logical NOT |
| `LOAD`     | Load variable |
| `STORE`    | Store to variable |
| `JMP`      | Unconditional jump |
| `JZ`       | Jump if zero |
| `CALL`     | Call function |
| `RET`      | Return |
| `PRINT`    | Print value |
| `HALT`     | Stop execution |

## 📚 Example Programs

### Hello World (with numbers)

```c
int main() {
    int x = 42;
    print(x);
    return 0;
}
```

### Factorial-like Calculation

```c
int main() {
    int n = 5;
    int result = 1;
    int i = 1;
    
    while (i <= n) {
        result = result * i;
        i = i + 1;
    }
    
    print(result);  // Outputs: 120
    return 0;
}
```

### Conditional Logic

```c
int main() {
    int age = 18;
    
    if (age >= 18) {
        print(1);  // Adult
    } else {
        print(0);  // Minor
    }
    
    return 0;
}
```

## 🛠️ Extending the Compiler

### Adding New Operators

1. Add token type in `token.h`
2. Update lexer in `lexer.c`
3. Handle in parser (`parser.c`)
4. Add bytecode operation in `bytecode.h`
5. Implement in code generator (`codegen.c`)
6. Implement in VM (`vm.c`)

### Adding New Data Types

1. Add type to `DataType` enum in `ast.h`
2. Update parser's type recognition
3. Implement type checking in semantic analysis
4. Update code generation for the new type
